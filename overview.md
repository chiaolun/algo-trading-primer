## Suggested source map

### Required sources

1. **Larry Harris, *Trading and Exchanges***
   Use for market structure, double-sided auction, liquidity, market orders, limit orders, bid/ask spread, brokers, exchanges, and trading rules. ([global.oup.com][1])

2. **CME Group Education and product pages**
   Use for futures contracts, expiration, roll, equity index roll dates, contract specs, and product-specific conventions. ([cmegroup.com][4])

3. **Databento or similar vendor documentation**
   Use for schemas, L1, L2, MBP, MBO, BBO, trades, and how data granularity affects simulation. ([Databento][2])

4. **QuantStart event-driven backtesting articles**
   Use for the architecture of market data events, orders, fills, and portfolio updates. ([QuantStart][11])

5. **Marcos López de Prado, *Advances in Financial Machine Learning***
   Use for backtesting risks, cross-validation, leakage, overfitting, and strategy-risk evaluation. O’Reilly’s table of contents lists a full backtesting section covering these topics. ([O'Reilly Media][12])

6. **Georgia Tech CS 7646: Machine Learning for Trading**
   Use as a course spine for implementation exercises involving ML, regression, and trading decisions. ([OMSCS][6])

### Optional advanced sources

1. **Cartea, Jaimungal, Penalva, *Algorithmic and High-Frequency Trading***
   Use for execution, limit order placement, market making, VWAP-style execution, and microstructure modeling. ([books.google.nl][15])

2. **Stefan Jansen, *Machine Learning for Algorithmic Trading***
   Use for Python ML workflows, feature engineering, model-driven strategies, and backtesting examples. ([GitHub][14])

3. **AlgoSeek documentation or catalog**
   Use for examples of futures trade bars, quote bars, trade counts, aggressor statistics, volume, and data format conventions. ([Algoseek][9])
